## 📈 Key Scientific Findings (At a Glance)

### The Discovery

**Ethylene triggers coordinated activation of isoflavonoid biosynthesis**

### The Evidence

**Metabolomics**:
- 43 metabolites significant (54% of total)
- Top fold changes: 12-13× (Log2 scale) = 4,000-8,000× (linear scale)
- Malonyl/acetyl conjugates most upregulated
- P-values: <10⁻⁷ to 10⁻⁸

**Proteomics**:
- 6 key enzymes upregulated
- Fold changes: 2.9-6.4×
- All P<0.05
- IFR (6.4×), CHI (5.1×), 4CL (3.9×), PAL (3.7×), IFS (3.2×), CHS (2.9×)

**Pathway Enrichment**:
- KEGG map01110: P=0.030 (SIGNIFICANT)
- Odds ratio: 10.43 (95% CI: [0.56, 195.35])
- PlantCyc: Biological concordance (ISOFLAVONOID-SYN)

**Integration**:
- Protein-metabolite correlation: r>0.85 (P<0.001)
- Coordinated pathway regulation confirmed

### The Impact

- **Agriculture**: Stress tolerance, disease resistance
- **Nutrition**: Health-promoting isoflavonoids
- **Environment**: Reduced pesticide use

## 🆘 Troubleshooting

### "I can't find a specific figure"

**Solution**: All figures are in `results/figures/pathway_analysis/`
```bash
ls results/figures/pathway_analysis/
```

### "I need to regenerate figures"

**Solution**: Run the generation scripts
```bash
python src/generate_pathway_figures.py
python src/generate_enhanced_figures.py
python src/generate_supplementary_materials.py
```

### "Figures look pixelated"

**Solution**: Use PDF versions (vector format, infinite scaling)
- PNG is for presentations/web
- PDF is for print/publication

### "I need different statistical thresholds"

**Solution**: Edit `src/statistical_analysis.py` and rerun
- Change `alpha` parameter
- Regenerate report

### "References aren't formatted correctly"

**Solution**: Use reference management software
- Import from `MANUSCRIPT_SECTIONS_COMPLETE.md`
- Reformat to journal style (EndNote, Zotero, Mendeley)

### "Need help understanding statistics"

**Solution**: Read in order:
1. `PLAIN_LANGUAGE_SUMMARY.md` (general explanation)
2. `STATISTICAL_ANALYSIS_REPORT.md` (detailed analysis)
3. `FINAL_PUBLICATION_PACKAGE.md` (reviewer responses)
